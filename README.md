# 爸爸媽媽小食堂

一個給家裡用的晚餐點菜 App。單一 HTML 檔案，不需伺服器，直接用瀏覽器開就好。

**[→ 立即使用](https://ssps6210.github.io/family-diner/)**

---

## 這是什麼

家裡吃飯，讓爸媽在廚房煮，讓其他人點菜。

用「愛心」當幣，不是真的錢。番茄炒蛋 2 顆愛心、三杯雞 3 顆，大家自己評估今晚要怎麼花。

內建 50 道台灣家常菜，熱炒、蛋豆腐、海鮮、青菜、湯、主食都有，直接就能用。

## 主要功能

| 功能 | 說明 |
|------|------|
| 菜單瀏覽 | 分類顯示，每道菜有手繪插圖（不需網路）|
| 點菜 / 下單 | 選好菜按「去下單」，填名字送到廚房 |
| 廚房訂單 | 廚房頁面即時看到誰點了什麼，可標記「做好了」|
| 改菜單 | 加菜、刪菜、改愛心數、上傳照片 |
| 愛心額度 | 設每人今晚幾顆，超了會提示 |
| 純離線 | 資料存在瀏覽器 `localStorage`，不連網、不上傳 |

## 怎麼用

### 最快的方式：直接開網址

用瀏覽器開 `https://ssps6210.github.io/family-diner/`，存到主畫面（Add to Home Screen）就像 App 一樣用。

### 本地開（完全離線）

下載 `index.html`，直接在瀏覽器開檔案即可，不需要任何安裝或伺服器。

### 多台裝置共用

這個 App 的資料存在每台裝置自己的瀏覽器，**不會跨裝置同步**。  
家裡同一台平板讓大家輪流點菜，廚房也在同一台上看訂單，這樣最簡單。

## 技術說明

- 單一 HTML 檔，零依賴，零 build step
- 插圖全部用 SVG 手繪在程式碼裡，離線也顯示
- 字體：[jf open 粉圓](https://github.com/justfont/open-huninn-font)（Google Fonts CDN，第一次開需要網路，之後瀏覽器會快取）
- 資料：`localStorage`（`mama-shitang-v2`）
